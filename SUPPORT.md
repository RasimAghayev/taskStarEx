# Support

## Where to ask questions

- **Bug / feature request**: open a GitHub issue using the templates in
  [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/).
- **General question / discussion**: use
  [GitHub Discussions](https://github.com/RasimAghayev/taskStarEx/discussions)
  on this repository (enabled).
- **Security vulnerability**: do **not** use an issue — see
  [`SECURITY.md`](SECURITY.md) for private reporting.

## Office hours

None — this is a single-maintainer personal-account project, not a
staffed project with scheduled office hours.

## Commercial support

None offered. This repository originated as an interview take-home
assignment (see `docs/ARCHITECTURE.md`) and is maintained on a
best-effort basis by its owner; there is no SLA and no paid support
tier.

## Response expectations

Issues and Discussions are read and triaged on a best-effort basis by
the repo owner. For anything security-related, see the severity/response
targets in [`SECURITY.md`](SECURITY.md) — those are the only part of
this project with a stated response-time commitment.
